WHAT THE AUDIT FOUND

ACCESSIBILITY

<html> HAD NO lang. Screen readers picked the wrong voice — Portuguese text read
with English phonetics. It now follows the language toggle (pt-BR / en).

TOASTS WERE SILENT. role="status" + aria-live="polite". "Backup restaurado" and
"Coleção exportada" were never announced. A confirmation that exists only visually
is not a confirmation for someone who cannot see it.

NO SKIP LINK. Roughly 110 navigation stops sit before the content on every view.
There is now a "Skip to content" link that appears on focus — positioned offscreen
rather than display:none, which would have taken it out of the tab order entirely.

CARD ART HAD NO alt. Three card <img> elements announced nothing. They now carry
the card name. The decorative hero coin keeps alt="" — announcing it is noise.

ICON-ONLY CONTROLS WERE UNNAMED: the − / + steppers, and the EN/PT buttons that a
screen reader read as two loose letters.

HIDDEN FILE INPUTS TOOK FOCUS. display:none is not enough in every browser; they
now carry tabindex="-1" and aria-hidden.

TOUCH TARGETS
Quantity steppers were 24px. There were also buttons at 28px and 30px. No control
declares under 32px now, and the test fails if one comes back.

MOTION
The hover lift was inline per card via style-hover. It is now .ink-lift — one rule,
inside @media (hover:hover). On touch there is no hover, so the effect used to
stick after a tap.

A CSS BUG THE TEST ITSELF CAUGHT
I placed @media (prefers-reduced-motion){ .ink-skip{transition:none} } BEFORE the
base .ink-skip rule. Same specificity means source order wins, so the
reduced-motion override did nothing at all. Moved after, with a test that checks
the ORDER rather than just the presence.

PERFORMANCE BUDGET
29 backdrop-filter declarations. Blur is the most expensive paint on the page and
the cost lands exactly on phone GPUs. Two changes:
  - at <=860px, blur is off. Glass surfaces keep their colour, they just stop
    blurring live.
  - PERFORMANCE MODE NOW DROPS BLUR TOO, not just the shader. The button promises
    lower cost; delivering half of it was a broken promise.

Found along the way: two 860px breakpoints written differently (@media( with no
space), which is why the test could only see one. Normalised.

A DUPLICATE DICTIONARY KEY
perRow already existed as '{n} / row' and I added a second one as 'row'. In JS the
last definition silently wins. Mine is gone, and the test now rejects any key
defined twice — i18n-contract checks parity and usage, but not duplication.

────────────────────────────────────────────────────────────
NOT DONE: COMPONENT LIBRARY

M2.7 listed component extraction. There are 1,231 inline style attributes in a
single file, and this app paints from inline styles by design — pulling them into
classes would delay first paint, which is the opposite of the goal. The real
standardisation came from the tokens (V5) and now from the motion system. Module
extraction belongs to M3, where it is already listed.
