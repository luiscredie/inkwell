FONT

"Atividade de Partidas" is a KPI label, and those render in Plus Jakarta Sans —
the body/UI family. So the ask is: no serif. Playfair Display is gone entirely.

--font-title and --font-serif now point at Plus Jakarta Sans, and Playfair is out
of the Google Fonts link — one less request and four weights that would never be
used. Zero "Playfair" and zero ",serif" left in the file.

Large headings were compensated: a grotesque at 44-48px needs more weight and
tighter tracking than a display serif at the same size, so those went from 700 to
800 with letter-spacing -.03em. Without that they would have looked thin and
loose where the serif used to carry them.

A BUG I INTRODUCED, FOUND AND FIXED

In the V5 token retrofit, my replacement of 'JetBrains Mono' with var(--font-mono)
also hit the token's OWN definition. It became:

    --font-mono: var(--font-mono), monospace

which is self-referential. CSS throws the declaration away, so since V5 every
tabular number in the app — match scores, replay log, prices, card IDs — has been
falling back to the system's generic monospace instead of JetBrains Mono.

No suite caught it. visual-contract checks that each token is DEFINED exactly
once, not that its value is valid. Now:

    --font-mono: 'JetBrains Mono', ui-monospace, monospace

Worth a glance at the replay log and price columns to confirm they look right
again.

CORE / INFINITY FILTER

Reuses legalInFormat(card,'core'), which already existed for deck validation and
reads legality.json when published, with CORE_SETS as fallback.

ONE DECISION TO CONFIRM. Infinity has no rotation, so a literal "Infinity" filter
would match every card and filter nothing. I built the pair as a useful opposite:

  Core      only cards legal in the current rotation
  Infinity  only cards OUT of rotation — the ones that exist in Infinity alone

Both chips toggle off to "all". Each carries a title tooltip saying exactly that,
so the short label cannot mislead.

If you meant Infinity literally — the whole pool, rotation ignored — it is a
one-line change. Tell me which.
