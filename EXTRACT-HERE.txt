────────────────────────────────────────────────────────────
WHY PWA FIRST, OUT OF WHAT M3 LISTS

It solves a concrete situation: checking your collection and decks at a game store
on bad wi-fi. The scanner needs an OCR and data-source decision first, and
telemetry has no outside users to measure yet.

────────────────────────────────────────────────────────────
A CACHING POLICY, NOT ONE BLANKET RULE

The strategy per file follows how that file actually behaves:

  app shell (html, js)   network-first   an update has to be able to land
  data-manifest.json     network-first   it is the VERSION POINTER — a stale one
                                         pins every other file to an old build
  versioned data         cache-first     the manifest names a version, so those
                                         files are immutable and safe to keep
  prices.json            network-first   they move daily; the app already labels
                                         staleness, so a cached copy is honest
  card art               cache-first     with a hard cap
  user data              NEVER           it lives in localStorage and Supabase; a
                                         cached copy could resurrect a deleted record

RULE ORDER MATTERS. data-manifest.json and prices.json are tested BEFORE the
generic .json rule, or they would never run at all. There is a test for that
ordering, not just for the rules existing.

The art cap is 600 entries, oldest evicted first. Without it, thousands of card
images would sit on disk forever.

The install uses c.add() per file rather than addAll(), because addAll fails the
ENTIRE service worker install if any single URL 404s.

────────────────────────────────────────────────────────────
UPDATES ARE OFFERED, NEVER FORCED

When a new version installs while a tab is open, a banner appears with a Reload
button. No automatic location.reload() — reloading mid-import would throw away the
preview you had not confirmed yet.

REGISTRATION IS GUARDED

The Inkwell.dc.html mirror opens from file://, where registering a service worker
throws. Registration checks for https? and for API support, and swallows failure —
a broken PWA must not stop the app from opening.

OFFLINE

A banner with aria-live that says WHAT STILL WORKS: collection and decks yes,
prices possibly out of date. A vague "no connection" would leave you unsure whether
to trust what is on screen.

ICONS

Generated from logo-coin.png at 192 and 512, with 10% breathing room on a #0a0c10
field, and declared maskable as well as any — without maskable, Android crops the
coin's engraving away.

Every manifest path is relative. Absolute paths break on a GitHub Pages project
site, which serves from a subfolder.
