Limites e metodologia

Fonte: partidas já sincronizadas em game_logs, com acesso restrito ao usuário autenticado. Não é feita consulta direta do navegador à API Duels.ink, nem exposição do token existente. Não atribuímos notas ou erros de mulligan sem revisar as ações.

Experimento independente do Inkwell live. Nenhum dado de partida é enviado a serviços externos pelo painel.
